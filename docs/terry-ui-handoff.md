## Launch

This machine already has the locked Python environment and built UI. From the repository root:

```sh
RUNTIME_MODE=offline .venv/bin/alibi serve --port 8010
```

Open http://127.0.0.1:8010 and choose **Open recorded investigation**. No API key or internet is needed for playback. Stop with Ctrl-C. On another machine, install Node 20+ and uv, then use `uv sync --frozen` and `./start.sh` as described in README.md.

The local Node/uv tools installed for this session live outside the repository in `../.tools/`. To rebuild here without modifying the system:

```sh
PATH="$PWD/../.tools/node-v22.15.0-darwin-arm64/bin:$PATH" npm --prefix web run build
```

## Delivered behavior

- Paper/ink layout: actual manifest sources on the left, paired evidence in the center, compact cited findings on the right. The discrepancy, human review controls and account/person boundary are visible at 1280×720. The layout stacks at narrow widths.
- One direct recorded-AI action, clearly separate fresh scripted investigations and replay provenance. No global blocked-AI alarm obscures offline playback.
- Aligned host/collector records with before/after context, labeled discrepancies, coverage details, full raw-line drawer, hashes and source provenance. Preview text removes only the repeated timestamp/host prefix; the drawer preserves the exact original line and scrolls horizontally.
- Source selection updates the paired file when one exists and highlights the relevant timeline lane. Every nonempty source artifact can open its first exact record. Recording-window declarations, surviving record bounds and known gaps remain distinct.
- Findings show an observation, status and citations; rationale, verifier notes, benign alternatives and assumptions expand. Uncalibrated confidence values are hidden. Full report summary and attribution limitations remain inspectable.
- Accept/Reject locks the existing report before Unseal. Reveal separates observable results from unobservable effects and keeps detailed precision/token/timing tables expandable. Failed scripted actions stay visible.
- Benchmark summary includes samples, evidence origin, inference/model, reference sources and a compact table. The equal-accuracy four-case AI pilot remains explicit; unrun arms have no invented measurements.
- Details drawer holds model/runtime, replay provenance, seed, hashes, measured usage, pipeline, notes and tool trace. It states that the spend ledger is not exposed by this server.
- Native dialogs handle Escape, focus containment and return. Reduced motion is respected. Reconnect preserves the report; changing case identity clears the previous report while restoration is pending.

No backend logic, scoring, simulator or model output was authored by this UI work. Generated contracts came from Eric's merge, not manual edits. No paid model calls were made; no spend ledger or recording was reset or rewritten. Development fixtures are isolated under `web/fixtures/` and never imported by the production UI.

## 60-second walkthrough

1. **0–10s:** Open the library's recorded investigation. Point to **Recorded AI run**, **Simulated evidence** and replay provenance. This is a saved real-model investigation, running offline.
2. **10–25s:** Read the aligned row: the local entry is missing; the collector has the session opening. Open that collector line, show the exact source and hash, then close with Escape.
3. **25–38s:** Open the finding's rationale/alternatives and a citation. Point out **account used** versus **human operator not established**. The evidence establishes credential use, not a person's guilt.
4. **38–48s:** Accept or reject the report. The report locks; only then does Unseal become available. Open the answer key and compare caught/missed effects and the failed collector-removal attempt.
5. **48–60s:** Close reveal, open Details for recorded usage/provenance, then show the benchmark's equal-accuracy pilot. If time permits, open the control case to show that ordinary activity produces no incident allegations.
