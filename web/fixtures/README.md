# UI development fixtures

These JSON files are not imported by the application. `capture_walkthrough.py` captures `library.json`, `runtime-offline.json` and `case-awaiting-review.json` from a temporary real offline ALIBI server. The review snapshot replays the committed real-model recording, with `inference_mode: RECORDED_MODEL` and `reveal: null`; it does not make a model call or hand-author AI output. `library-empty.json` and `library-unavailable.json` are explicit browser test inputs for empty/error responses.

The present server does not implement open-ended questions, source experiments, report export or captured-Linux import. The production UI reports those capabilities unavailable and does not send speculative API calls. No invented success payload for those routes is represented as an implemented contract. Integrate the actual additive contracts from Eric when delivered.

`comparison-not-assessable.json` is generated by the real comparison logic from the existing test mini-bundle builder with no collector. It verifies that an unavailable witness cannot become a clean result.
