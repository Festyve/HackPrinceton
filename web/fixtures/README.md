# UI development fixtures

These JSON files are not imported by the application. `capture_walkthrough.py` captures `library.json`, `runtime-offline.json` and `case-awaiting-review.json` from a temporary real offline ALIBI server. The case is generated by the existing scripted investigator, with `reveal: null`, not hand-authored AI output. `library-empty.json` and `library-unavailable.json` are explicit browser test inputs for empty/error responses.

The present server does not implement open-ended questions, source experiments, report export or captured-Linux import. The production UI reports those capabilities unavailable and does not send speculative API calls. No invented success payload for those routes is represented as an implemented contract. Integrate the actual additive contracts from Eric when delivered.
